# 光轴工坊

用浏览器打开 `index.html` 即可使用，无需安装依赖或联网。

- 配置层板长宽、厚度、材质、圆角、孔径及对称孔位。
- 孔距边支持孔中心或孔边缘两种基准；图纸统一标注孔中心。
- 设置立柱长度、层数、均分或逐层板面高度。
- 设置光轴直径、十字夹孔径、夹具体尺寸、单双夹方案、脚轮。
- 拖动旋转、滚轮缩放；切换装配效果、打孔图、材料清单。
- 导出 PNG / SVG / CSV，保存并载入 JSON 配置。

“参考图一”按 380 × 140、3 mm 304 不锈钢、R5、4 × Φ8、左右孔边净距 10 mm、前后孔边净距 6 mm 录入。对应孔中心距边为 14 / 10 mm，原图标注如有不同理解可直接修改。

“参考图二”为结构和材质风格预设：600 × 300 层板、1200 mm 立柱、三层、双十字夹、脚轮。照片无尺寸标注，默认数值仅为示例。

预览为按参数生成的立体装配示意。夹具采用通用简化模型，长短横杆分别位于上下两只夹具中心高度。横杆下料长度为孔中心跨距加一个夹具体长度（两端各伸出半个夹具体）。加工前按实购夹具、脚轮接口及承重要求复核。
